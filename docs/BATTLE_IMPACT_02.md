# 战斗演出版 · IMPACT-02

开发分支：`feature/animated-battle-v2`。不替换既有 v2.0.0 Release。

## 直接体验

```powershell
.\RUN_WINDOWS.bat --battle-preview
```

或双击 `PREVIEW_BATTLE.bat`。窗口标题及战斗左上角显示 `IMPACT-02`。预览提供三位伙伴，独立于旅程存档；完成后 R 重来、Esc 退出。普通旅程中的战斗使用同一套控制器。

## 改动

技能按蓄力、出招、命中、收招的时间线运行，只有命中点才改变伤害、治疗和状态。敌方自动接招，不再要求玩家按 Enter 代替敌方行动。技能期间锁定施法者与受击对象，避免换人逃避伤害或连按重复触发。

旅人和伙伴同时站在由现有正式地图素材搭建的战场；灯塔采用石地、废墟立柱与蓝火，不再使用绿色椭圆平台。角色显示放大，动作分别采用前冲、跃起、后仰与退回；泡泡弹道、晶弧共鸣、治愈光圈、Boss 蓄能冲击配合血条缓降、伤害数字和小幅镜头震动。动画使用现有正式精灵帧与程序编排，没有替换 v7/v8 资源。

Space 可在敌方命中前约 0.20 秒内触发精准格挡，受到原伤害的 45%；不操作仍按正常伤害进行。每次敌方行动仅接受一次格挡尝试，不能连按刷判定。

水流的单次减伤与潮湿持续时间分开：敌方第一次出击消耗减伤，但潮湿保留至下一次我方行动，可接晶弧的 38 点基础共鸣伤害；未及时使用时会自然失效。

最后一击先完成受击、消散，再进入原有 1 秒静音黑屏 → 战后对话 → 结局。音乐系统不重启，既有存档结构不变。

## 验证

`tools/test_battle.py` 覆盖命中时刻、一次性结算、自动敌方回合、目标锁定、潮湿联动、格挡、防连按、倒下伙伴、旅人后备攻击、失败回营地、预览存档隔离。
`tools/test_postbattle.py` 继续覆盖黑屏/战后对话/结局和存档；`tools/test_battle_visuals.py` 从实际渲染器捕获固定输入序列，字幕为明确标注的 QA 文本，不是假称真实音乐识别。
