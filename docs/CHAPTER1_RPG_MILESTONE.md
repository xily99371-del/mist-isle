# Chapter 1 expanded RPG milestone

## Added this milestone
- Inventory screen opened with I: fruit, shells, crystals, health and companion levels.
- Island route map opened with M: camp, grove, tide ruins and lighthouse courtyard, with progression-based unlock indicators.
- Combat skills now have distinct roles:
  - Moss Lumi restores 18 HP and deals minor light damage.
  - Moatail applies Soaked and deals water damage.
  - Crystal Gecko deals increased damage to a Soaked enemy.
- Enemy turns have a round counter and damage feedback.
- Defeating an enemy grants 20 XP to the active companion; 50 XP advances one level.
- Boss victory grants bonus crystals and shells.
- Companion levels and XP are stored in the save file.
- F5/F9 save/load can be used while journal/inventory/map overlays are open.

## Controls
- WASD / arrows: move
- Shift: dash
- E: interact / gather
- Tab: cycle owned companions
- J: field journal
- I: inventory
- M: island map
- F5: save
- F9: load
- Battle: 1/2/3 select skill, Enter confirm

## Current quality boundary
This is a more complete playable chapter prototype, not a finished commercial-grade game. The combat loop, progression and menus are implemented in the code, while final hand-authored pixel animations, full scene art, soundscape and actual end-to-end human playtesting remain follow-up work.
