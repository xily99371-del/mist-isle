# 月夜入口 TITLE-01
基于 v3.0.0 完整旅程，仅更换入口呈现与菜单操作。战斗、脚步声、剧情和存档格式不变。

原图文件：`assets/ui/title_cover.png`，用户本轮上传选择的站立旅人月夜版，非坐姿三伙伴版。
SHA-256：`52373edc2423dcd2ff7c3be88b12228ee6d478097c1593f75a92b967836d3d1e`。
尺寸：1672 × 941。原始 PNG 不裁切、不重画、不替换人物，不使用结局 CG。
图中的金色“开始冒险”保留为主操作样式，实际焦点由移动菱形和轮廓单独标识。

鼠标四个按钮均可操作；方向键/W/S 选择，Enter/Space 确认，F9 继续存档。
无存档时继续入口提示暂无存档；损坏存档会显示读取失败，不会开始新游戏。
新冒险存在存档时先确认，默认返回；确认后将旧文件另存到递增编号备份，备份失败则不开始。
设置有音效音乐开关、字幕开关和无边框显示切换，本次运行有效。
退出有二次确认。输入坐标与游戏共用 16:9 viewport，黑边点击无效。
贴图仅初始化时加载、退出时释放；菜单不重建世界地面缓存，不启用视频/额外解码。

验证：自动测试菜单命中、HiDPI/超宽/方形窗口坐标、设置、返回、读档、确认和备份失败。
`tools/title_visual_qa.c` 用实际渲染器截取六种菜单状态；缺少原图时明确提示，不使用其他画面冒充。

注意：原图必须一并安装。代码仓库构建缺少原图时只提供明确的缺图备用入口。
