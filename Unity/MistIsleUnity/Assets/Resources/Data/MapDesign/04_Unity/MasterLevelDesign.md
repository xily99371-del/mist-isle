# Mist Isle 第一章地图设计总规范（Codex 施工版）

## 1. 目标与边界
本包定义第一章五张地图之间的空间连接、关卡职责、关键点坐标、出口触发和 Unity Tilemap 实现规则。PNG 是视觉参考；JSON 是坐标与状态的结构化依据；Markdown 解释设计意图和验收标准。若 PNG 与 JSON 冲突，以 JSON 的尺寸、坐标和连接定义为准，视觉布局需回到设计阶段修订，不允许 Codex 自行猜测。

## 2. 世界闭环
M00 海岸营地 → M01 潮风小径；M01 是交通枢纽，可自由前往 M02 辉光林地或 M03 潮汐遗迹；M02 击败花冠鹿灵获得森印；M03 击败断潮蟹王获得潮印、击败棱晶蛇王获得晶印；收齐三印后通过 M03 北出口进入 M04 灯塔庭院，开启三印之门并挑战最终 Boss 回响观测者。所有支线都有返回枢纽的出口，最终通关路径完整闭合。

## 3. 唯一坐标标准
- Tile：16×16 px；Pixels Per Unit：16；Unity Grid Cell：1×1。
- 原点位于左下角；X 向东递增，Y 向北递增。
- JSON 中 `xy` 为 tile index；`rect` 为 `[x,y,width,height]`，左下角为起点；所有矩形采用左闭右开范围。
- 地图尺寸以 `WorldConnections.json` 为唯一权威：M00 64×48、M01 80×56、M02 96×72、M03 112×80、M04 80×64。

## 4. 地图职责
### M00 海岸营地
安全教学和长期 Hub：出生码头、篝火存档/合成、补给商店、旅人小屋、拾光工作台、储物棚、任务告示板；不生成随机野生战斗。唯一世界出口 EAST_01。
### M01 潮风小径
世界交通枢纽：中央溪流木桥连接西入口；北接 M02，东接 M03；采集草甸、野生遭遇草丛、瞭望台和宝箱作为主线以外的探索内容。支线必须回接主路。
### M02 辉光林地
环形探索路线：萤火草甸、古树环庭、树根桥、瀑布观景台、隐藏空地、森林封印门和花冠鹿灵守卫台。树根桥/植物机关由对应伙伴能力激活；胜利给予森印。
### M03 潮汐遗迹
双翼结构：潮汐神殿（水位/渠道/浮台/断潮蟹王）与晶簇档案馆（导能/晶体机关/棱晶蛇王），由遗迹前庭和中央水道连接。两个守卫分别给予潮印与晶印。北出口要求三枚封印。
### M04 灯塔庭院
最终区域：南入口、登塔阶道、前庭回廊、半山营地、共鸣广场、三印之门、灯塔前庭、最终战场。三印门未解锁时必须有实体阻挡；解锁后清除碰撞并触发演出。

## 5. Unity Tilemap 图层
建议每张地图使用以下独立 Tilemap：
1. `Ground`：草地、泥土、沙滩、石板路。
2. `Water`：海水、河流、浅滩、水渠、瀑布脚下水域。
3. `TerrainBack`：悬崖背面、远景岩壁。
4. `Collision`：不可通行地形与建筑基础碰撞；使用 TilemapCollider2D + CompositeCollider2D。
5. `PropsBack`：树冠后层、房屋后层、桥梁背景。
6. `Objects`：宝箱、机关、工作台、采集物、门。
7. `Characters`：玩家、NPC、野生宠物、守卫。
8. `PropsFront`：树冠前景、屋檐遮挡、前景装饰。
9. `Triggers`：出口、遭遇区、Boss 触发区、剧情触发区。
10. `VFXMarkers`：萤火、瀑布喷雾、封印光效锚点。

## 6. 碰撞规则
- 不可通行：深水、地图边缘悬崖、实心建筑地基、封闭门、不可攀爬高台侧面。
- 可通行：主路、草地、木桥、码头、明确标记的浅滩、楼梯和坡道。
- 建筑碰撞按地面占地轮廓设置，不能用整张建筑 Sprite 的矩形碰撞；灯塔/房屋/不规则废墟优先使用 PolygonCollider2D。
- 门、宝箱、NPC 和采集点的交互 Collider 必须是 Trigger，不能阻塞道路。
- 高差由楼梯/坡道连接；视觉上有高台但没有连接件的区域不得标记为可达。

## 7. 连接与场景切换
所有出口 ID 在 `WorldConnections.json` 中唯一。出口矩形进入触发后，加载目标 Scene 并将玩家放到对端 `spawn` 坐标，设置 `facing`；返回时优先恢复离开前坐标。M04 的入口必须在缺少任意一枚 Seal 时保持锁定。不得在场景脚本中硬编码另一张地图的临时坐标；统一从连接数据读取。

## 8. 资源和遭遇
资源点必须有 ID、资源类型、刷新时间和采集状态；宝箱有唯一奖励表和一次性标记；野生遭遇区有物种池、等级区间、触发概率和冷却。M00 不安排随机战斗；M01 教学遭遇；M02/M03 提供区域特色物种。不要把示意图里的图标直接当作实际精灵资源。

## 9. Codex 分阶段施工顺序
1. 只搭 M00 灰盒：地形、海岸边界、建筑地基碰撞、出口和摄像机；先用纯色方块验收移动。
2. 接入 M00 正式 tileset 和场景物件，完成 NPC、篝火、商店、拾光工作台。
3. 搭 M01 并验证三个出口与 M00/M02/M03 坐标配对。
4. 搭 M02，验证环形路线、树根桥开关、守卫触发和森印奖励。
5. 搭 M03，分别验证水位机关、浮台、导能机关、两个守卫和三印门前置。
6. 搭 M04，验证三印门碰撞切换、Boss 触发和结局回路。
7. 完成全图连通性自动检查和逐张 Play Mode 试玩。

## 10. 验收清单
- [ ] 五张地图尺寸与 JSON 一致。
- [ ] 所有出口 ID 唯一且双向配对正确。
- [ ] 从 M00 可到达 M01，M01 可到达 M02/M03。
- [ ] M02/M03 都能返回 M01。
- [ ] 三枚 Seal 均可通过各自守卫获得。
- [ ] 三枚 Seal 缺一不可进入 M04 的最终门。
- [ ] M04 可返回 M03，Boss 胜利能完成第一章。
- [ ] 所有主路线无碰撞断点、无软锁、无不可达 POI。
- [ ] 建筑碰撞按地基，不出现角色穿楼或被空气墙挡住。
- [ ] 摄像机边界不露出地图外区域。
- [ ] 资源点、宝箱和遭遇区不会阻断主线。

## 11. 文件优先级
1. `00_World/WorldConnections.json`：世界地图、连接与坐标规则的权威来源。
2. `00_World/ProgressionGraph.json`：剧情与封印条件权威来源。
3. 各地图 `Layout.json`：地图坐标、路线、出口、POI、碰撞粗分区。
4. 各地图 `Interactions.json`：交互点数据。
5. 各地图 `Design.md`：地图意图和施工说明。
6. `Blueprint.png` 与总览 PNG：视觉参考，不覆盖结构化数据。
