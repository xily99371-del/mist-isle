# M02 辉光林地 / Glowglade

- Size: 96 × 72 tiles.
- Role: forest exploration branch; reward is the Forest Seal.
- Exit: SOUTH_01 ↔ M01.NORTH_01.
- Landmarks: firefly meadow, ancient tree court, root bridge, waterfall overlook, hidden clearing, forest seal gate and guardian arena.
- Mechanics: Moss switch, root bridge traversal, luminous resource gathering and optional hidden chest.
- Guardian: 花冠鹿灵. Defeating it grants `forest_seal`.
