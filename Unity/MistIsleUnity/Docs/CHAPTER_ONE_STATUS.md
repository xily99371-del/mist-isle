# 第一章开发记录

目标：第一章完整版，18–24 个可收集形态、四枚封印、观测者终局与初始伙伴超进化；60–90 分钟为尚待实际游玩验证的目标。

## 已接入的内容

- 海岸营地、潮风海岸、辉光林地、潮汐遗迹、鸣晶高地和灯塔，十八个用明确坐标编排、运行时构建 Tilemap 的连通房间。
- 旅人四方向移动及相机跟随；房屋足迹、树干、围墙、河岸和支路门体真实碰撞。
- Watcher 的免费恢复、队伍与伙伴寄存；拾光独立的捕获引导。
- 御三家选择、六只随身、三只部署、后备换人、整队倒下返回营地。
- 材料拾取、两条篝火配方、偏好投喂、削弱/状态/工具影响捕获。
- 属性倍率、技能、缠绕/弱化状态、经验、等级、亲密度和三种进化。
- 伙伴能力实际移除支路障碍，存读档保留道路与采集状态。
- 三枚区域封印解锁灯塔；观测者第四封印战后，进入同一角色的终局第二阶段。
- 终局明确蓄能预警、下一轮冲击、静默、玩家呼唤初始伙伴、恢复队伍及手动使用“归航回响”。

## 内容边界

十八个可收集形态包含三只基础伙伴、三种进化、六只既有野生形象和六只新候选。守卫、别名和观测者第二阶段不计入十八个伙伴。新候选为露芽绵羊、潮泡海獭、晶角蜗牛、余烬小狐、风铃飞蛾、礁岩石龟，均标记 designApprovalPending，不能当作用户已经确认的正式设定。

已有角色的透明整理使用正式图板作为参考，没有更改既定服装、发色及配件。旅人和 Watcher 的四方向动画使用旧版透明资源的隔离副本；生物与拾光目前以独立静态图为主。尚未达到整套制作动画与统一像素精度的最终美术标准。

未选择的御三家暂以两枚封印后的营地重逢入口获取；完整支线剧情、第一章文本演出、地图细节、无障碍与时长平衡仍需继续制作。不可将此原型宣称为已完成的正式发行版。

## 存档与原版隔离

Unity 独立产品名与 persistentDataPath，保存 schema 2 JSON。支持 schema 1 缺省字段补齐、超额伙伴转入寄存、坏档从备份恢复、未来版本拒读；开始新旅程前归档已有进度。探索定时、采集、制作、恢复及战斗结束后保存；战斗中不保存中间状态。

原 C/raylib v3.0.1 源码、发行文件与二进制旧档保持隔离。所有新内容均在 Unity/MistIsleUnity。当前分支 unity/reboot-foundation，未经用户另行授权不合并 main。

## 验证

- EditMode：35 通过，0 失败，覆盖战斗/技能/捕获/成长/换人/寄存/四封印/终局完整可达性，以及存档迁移、备份和旧 C 文件保护。
- PlayMode：7 通过，0 失败；另 1 项批处理 UI 截图验收明确跳过。通过项覆盖十八房间连接、四守卫位置、出生安全、Rigidbody2D 实撞房屋、资源与出口、真实能力开路、新旅程至合成/存读档会话流程。
- 批处理能获得世界截图，但未触发 IMGUI 重绘；这些图标记 world-only，不能声称标题/HUD 通过。
- 正常 Windows Player 已实际启动，并用窗口内点击验证标题、新旅程、御三家选择与营地对话。截图只截取游戏客户区。检查发现的中文文本裁切已修复；完整人工通关与全部菜单仍待后续试玩。
- 独立美术资源验证通过：十八种可收集形态、四守卫、拾光、旅人/Watcher 三十二帧、四十八地面图块。此结果只代表资源结构和接入，不代表制作动画或人工美术终审通过。

日志、NUnit XML 与截图保留在 `Builds/Verification/20261117`；可使用 `Tools/Verify-Unity.ps1 -BuildWindows` 复现隔离验证。截图检查不代替完整玩家试玩和 60–90 分钟时长验证。
