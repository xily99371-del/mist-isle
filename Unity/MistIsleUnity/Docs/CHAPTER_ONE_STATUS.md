# 第一章开发记录

目标：第一章完整版，18–24 个可收集形态、四枚封印、观测者终局与初始伙伴超进化；60–90 分钟为尚待实际游玩验证的目标。

当前内容版本为 **0.3.0**，Windows 输出路径为 `Builds/OpeningPolish/Windows-0.3.0/MistIsle.exe`。本轮最终验证记录留待实测后补充，下方保留 0.2.x 与 0.1 的历史结果。

## 已接入的内容

- 海岸营地、潮风海岸、辉光林地、潮汐遗迹、鸣晶高地和灯塔，十八个用明确坐标编排、运行时构建 Tilemap 的连通房间。
- 旅人四方向移动及相机跟随；房屋足迹、树干、围墙、河岸和支路门体真实碰撞。
- Watcher 的免费恢复、队伍与伙伴寄存；拾光独立的捕获引导。
- 御三家选择、六只随身、三只部署、后备换人、整队倒下返回营地。
- 材料拾取、两条篝火配方、偏好投喂、削弱/状态/工具影响捕获。
- 属性倍率、技能、缠绕/弱化状态、经验、等级、亲密度和三种进化。
- 伙伴能力实际移除支路障碍，存读档保留道路与采集状态。
- 三枚区域封印解锁灯塔；观测者第四封印战后，进入同一角色的终局第二阶段。
- 终局明确蓄能预警、下一轮冲击、静默、玩家呼唤初始伙伴、恢复队伍及手动使用“归航回响”。

## 内容边界

十八个可收集形态包含三只基础伙伴、三种进化、六只既有野生形象和六只新候选。守卫、别名和观测者第二阶段不计入十八个伙伴。新候选为露芽绵羊、潮泡海獭、晶角蜗牛、余烬小狐、风铃飞蛾、礁岩石龟，均标记 designApprovalPending，不能当作用户已经确认的正式设定。

开场返工后，旅人和拾光直接沿用正式 `pixel_people.png` 的原像素，每人四方向、每方向三帧，共二十四张独立 128×128 帧；保留前景原 RGB，仅清理连通纸底，统一脚底、Pivot 和 Point 采样。Watcher 继续使用旧版透明资源的隔离副本。开场御三家与潮壳蟹也直接裁取正式像素图，替换此前不合适的静态整理图。来源、坐标和验证方法记录在 `ART_IMPORT_MANIFEST.json`。

0.3.0 的对话改用正式高清人物立绘：旅人来自 `E:/Projects/美术设定/main_character_design_sketch.png`，拾光来自同目录的 `guide_character_design_sketch.png`，资源键分别为 `Art/Portraits/TravelerApproved`、`Art/Portraits/ShiguangApproved`。两幅原画的纸底与局部景物同角色边缘相连，因此保留原纸底卡片和原始像素，不强行抠除衣服、头发或鞋边。Watcher 沿用仓库已批准的 `assets/characters/portraits/watcher_portrait.png`，以隔离副本清理背景后接入 `Art/Portraits/WatcherApproved`。对话立绘与地图像素演员分别使用对应资源，未用地图小人放大替代立绘。

三位人物的地图站姿统一为 **1.62 世界单位的实际可见高度**。运行时按透明度测量每个朝向的中立参考帧，该方向的所有行走帧共用固定缩放和脚底偏移，避免透明画布不同导致 Watcher 显著偏大，也避免旅人转身突然长高。旅人和拾光三列的语义为中立、第一侧支撑、另一侧支撑，步序使用 **0 → 1 → 0 → 2**；帧切换只由 `SpriteFrameAnimator.LateUpdate` 的单一时钟驱动，朝向采样不再反复重置计时。源图正面与背面的两侧步幅差异仍弱，需要后续制作原画动作，当前调整不能替代完整精修行走动画。

海岸营地 `camp-0` 已按码头货运、照护屋庭院、补给平台、篝火与香草地、伙伴小院及水边花园分区；首遇海岸 `coast-0` 加入废弃勘测棚、与海面相连的潮池入口、岩台和避风蟹湾，路径绕水岸延伸。海水与潮池使用独立碰撞网格，细化岸线、池边及石墙/箱桶/岩台的实物足迹，保留带路路线和出口内侧的通行空间。其余十六间房仍是待深化的章节草稿，不能把开场的改善说成全部地图已经精修。

封面保留原版正式标题画面，仅使用清理过的菜单局部覆盖烘焙按钮，角色、Logo、月亮与灯塔仍用原图像素；菜单使用真实按钮与键盘焦点。详见 `TITLE_OPENING_REVIEW.json`。

未选择的御三家暂以两枚封印后的营地重逢入口获取；完整支线剧情、第一章文本演出、地图细节、无障碍与时长平衡仍需继续制作。不可将此原型宣称为已完成的正式发行版。

## 存档与原版隔离

Unity 独立产品名与 persistentDataPath，保存 schema 3 JSON。支持 schema 1/2 迁移且保留原队伍、封印、背包与章节进度，已有旅程不强制重走新开场；新旅程支持选伙伴前的存档恢复。超额伙伴转入寄存、坏档从备份恢复、未来版本拒读；开始新旅程前归档已有进度。探索定时、采集、制作、恢复及战斗结束后保存；战斗中不保存中间状态。

原 C/raylib v3.0.1 源码、发行文件与二进制旧档保持隔离。所有新内容均在 Unity/MistIsleUnity。开场返工分支为 unity/opening-polish，未经用户另行授权不合并 main。

## 开场返工

码头抵达 → Watcher 接应与照护定位 → 拾光介绍三位伙伴 → 每位伙伴独立初见与同行回应 → 为受渔线惊吓的潮壳蟹采集食材 → 篝火制作莓果团 → 拾光沿海岸带路、等待玩家 → 轻柔牵制、投喂或共鸣的首次捕获 → 返回 Watcher 治疗 → 开放章节探索。

教学战不消耗过早使用的唯一食物，不会误击倒潮壳蟹；首次正确安抚后投喂/捕获保证成功，降低开场挫败。正常野生战继续使用原有捕获规则。开场同伴不会在小院重复出现，获救的潮壳蟹不会继续作为野生遭遇刷新。

正常 Editor 自动重放使用游戏自己的截图接口，和窗口键鼠试玩分开记录。Windows 锁屏时停止桌面交互；0.2.0 初期仅验证过部分界面，0.2.1/0.2.2 后续已完成开场窗口输入测试，具体范围见各次记录。第一章完整人工通关仍待进行。
