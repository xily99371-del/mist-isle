# M01 潮风小径 / Tidewind Path

- Size: 80 × 56 tiles.
- Role: traffic hub connecting M00, M02 and M03.
- Exits: WEST_01 ↔ M00.EAST_01; NORTH_01 ↔ M02.SOUTH_01; EAST_01 ↔ M03.WEST_01.
- Landmarks: stream and wooden bridge, lookout plateau, gather meadow, encounter grass, treasure chest and two optional shortcuts.
- Encounters: introductory wild creatures; teach inspection, weakening and feeding/capture.
- Rule: the main route stays traversable without a special pet ability; abilities reveal shortcuts and optional rewards.
