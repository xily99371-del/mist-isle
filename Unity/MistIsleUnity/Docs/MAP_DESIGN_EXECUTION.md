## 实现与质量目标

当前已开始：原数据读取、五图第一轮构建、320张原像素独立地形格、商店交易、计时资源、新旧地图存档迁移，以及剧情与机关/守卫接入。动态水面、真实局部灯光、岸线泡沫、森林萤火、遗迹导能和灯塔扫光正在随图验收；独立商店素材按蓝图补充。

后续必须逐区达到以下标准，不能用一次世界截图或BFS通过代替：

1. 先M00：构图、海岸高差、建筑规模、花草和光照接近蓝图，完成开场至出营的窗口试玩；商店、篝火、寄存和任务线索可实际使用。
2. M01：实走三个出口和往返、桥/溪流碰撞、主路与可选支路；采集→卖出→补给→遭遇→捕获→升级有明确反馈。
3. M02：真正闭合的森林探索、根桥状态变化、瀑布与隐藏区、生态恢复的可见后果，以及有意义的守卫试炼。
4. M03：两翼可自由探索；水位/渠道与浮台实际改变通行；导能路径有状态反馈；两场守卫有不同玩法要求。
5. M04：分层台阶与前景遮挡、三印插入/门的实际碰撞演出、观测者两阶段及初始伙伴觉醒、通关捷径和回营收束。
6. 最后整章：不同初始伙伴、两条分支先后、资源经济、失败与返回、技能/克制/养成节奏、旧档兼容、帧率与60–90分钟目标均需实测。

包内区域地形是换色版本，缺完整边角、过渡、独立地标与动画。新增资源采用独立文件、来源记录、透明度/Pivot/采样核对，保留正式人物设计。优先补真实用于场景的地形过渡和地标，避免整张设定图直接充当地图或Sprite Sheet。
