# 雾屿回响：音乐与音效

| 游戏位置 / 状态 | 音轨 | 播放方式 |
|---|---|---|
| 标题、海岸营地（主地图） | 用户提供的《传说之下》 | 从开头循环 |
| 辉光林地 | Forest Mixtape | 从开头循环 |
| 潮汐遗迹 | Sacred Play, Secret Place | 从开头循环 |
| 灯塔庭院入场、战前对话、Boss 战 | Enemy — Imagine Dragons & JID | 同一流连续播放；进入对话或战斗不会重播 |
| Boss 刚被击败后的 1 秒黑屏 | 无 | 立即停止音乐和残留音效；不可跳过 |
| 击败 Boss 后的对话、灯塔庭院、结局 | 蔡健雅《晨间新闻》 | 首次从 01:13.000 开始；播完后再次从 01:13 开始 |

音乐文件由项目使用者提供。`import_manifest.json` 记录源文件校验值、响度处理与时间对齐结果。音乐经过等响度处理，未剪辑歌曲内容；其版权归原权利人所有，不属于项目中 Kenney 素材的 CC0 许可。

`sfx/` 中的草地声改用 Blender Foundation《Yo Frankie!》明确标注的左右脚踩草录音（CC BY 3.0），石路声改用 Kenney Impact Sounds 的短促 concrete 落脚声（CC0）。不再使用上一版 Fantozzi 的 Sand/Stone 素材，不混入沙砾或碎石拖尾。来源、许可和加工署名见 `FOOTSTEP_CREDITS.md`。

每种材质六个播放变体。草地由两段真实左右脚录音派生，石路由五段落脚声派生；变体做轻微均衡与响度区别，不冒称独立录音。主地图、辉光林地固定踩草；潮汐遗迹、灯塔庭院固定硬石路。只跟随实际位移发声，不因雨天切换材质。

`footsteps_manifest.json` 记录来源与校验值。开发者可运行 `tools/import_footsteps.py`，使用仓库自带的 `third_party/audio/clean_footsteps/` 原始录音重建；普通编译和运行直接使用 WAV，无需额外下载或 ffmpeg。原有其他音效不变。

## 同步字幕

`enemy.tsv` 使用 UTF-8：`起始秒<TAB>结束秒<TAB>英文<TAB>中文<TAB>强度（可选）`。主歌、副歌、说唱与结尾均有逐句字幕，乐器段只显示音乐波形。字幕直接读取音频播放位置，不使用场景计时器；循环、切窗暂停后恢复时仍使用同一时间轴。

**字幕来源：** 英文依据用户上传的 `Imagine+Dragons&JID+-+Enemy.mp3`，使用 faster-whisper 语音识别转写，再由助手整理；保留的制作记录包含 small.en、large-v3-turbo 和 medium 的分段识别结果。中文为助手整理的项目自译。时间轴参考识别时间戳后逐句编排，当前共71组字幕。源音频校验值记录在 `import_manifest.json`。

当前没有可引用的官方歌词页、现成LRC或官方中文译文来源。播放连续性、字幕出现时机与排版已经验证；英文逐字准确性及中文翻译尚未完成对照权威歌词的逐句验收，尤其说唱段不能视作已经权威核验的歌词文本。

战后流程为：击败 Boss → 完全静音黑屏 1 秒 → 四句战后对话与《晨间新闻》01:13 同时开始 → 对话结束自动进入结局动画。动画沿用对话期间的播放进度；第一次通关无需再走回祭坛。黑屏期间也隐藏歌词、提示和性能浮层。

`enemy_energy.tsv` 是该音频每秒 20 个采样的音量包络，用于边缘灯光随音乐明暗变化。它在准备素材时生成；游戏中不执行整曲解码或频谱分析。

## 操作与行为

- `F6`：声音开关，涵盖 BGM 与音效。静音不重置播放位置。
- `F8`：Enemy 字幕及边缘灯光开关。
- `Shift` 或 `Space`：冲刺。
- 切出游戏窗口时暂停游戏与音乐，返回后接续同一位置。
- 音频设备不可用时，仍可继续游戏。

Windows 和 Raspberry Pi 的发行包均需保留完整 `assets/audio/` 与 `assets/fonts/` 目录。
